# Antigravity の役割（coresynth）

このリポジトリのコードはメンテナーとAIであるClaudeが `CLAUDE.md` と `.claude/rules/*.md` の仕様に沿って実装したもの。Antigravity はここでは **レビュー・検証役** として動く。新規コードを自発的に書く役割は想定していない。

## やってよいこと
- 既存コード・テスト・ドキュメントを読んで正確性・一貫性・仕様との整合性を確認する
- 明確なバグを見つけた場合は、その場で修正してよい（何が誤りで、なぜその修正が正しいかを説明する）
- バグ修正に伴って必要なリファクタリングも許可する（バグ修正のスコープを超えて肥大化させない）

## やらないこと（明示的な指示がない限り）
- 新機能の追加、API の再設計、仕様に無い挙動の実装
- バグ修正と無関係な広範囲リファクタリング・抽象化の追加
- `CLAUDE.md` や `.claude/rules/*.md` に矛盾する独自判断での仕様変更

## 判断に迷う場合
明確なバグではなく設計判断・仕様解釈に関わる指摘は、勝手に直さず問題点として報告するにとどめる。

## 参照すべき一次情報
- プロジェクト概要・横断ルール: リポジトリルートの `CLAUDE.md`
- 手法ごとの理論的根拠・アルゴリズム決定事項: `.claude/rules/*.md`（該当手法のコードを見るときは対応するファイルを読んでから当たること）
- ベンチマーク・論文照合表: `.claude/docs/*.md`

`.agents/rules/*.md` 配下の他ファイルは上記一次情報の要約・運用ルールであり、内容が食い違う場合は `CLAUDE.md` 側を正とする。
