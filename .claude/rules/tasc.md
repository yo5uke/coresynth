# TASC（Rho et al. 2026）

$$z_{t+1} = A z_t + C + \eta_t, \quad y_t = \mu + W z_t + \varepsilon_t$$

EM アルゴリズム（E-step: カルマンフィルタ + RTS スムーザ、M-step: 期待完全データ対数尤度の厳密な最大化）。Joseph form で数値安定化。**推論関数・`conformal_inference()` とも未対応**（本パッケージで推論ツールを持たない唯一の手法）。論文は状態共分散から予測区間を出している（S.6.1・S.6.2）が未実装。

**状態次元 `r` は固定 2**: GSC/MC/SI は論文のルールでデータ駆動選択するが、論文自身が d をハイパーパラメータとしてユーザーに指定させている（Prop 99 で d=2、他は d=5）。データ駆動の規則は無い。

**M-step は Algorithm 7 どおり**（1.1.0 で作り直し）: 旧実装は W・R・Q の更新を平滑化平均だけで計算し（事後共分散 P^s を落とした hard EM）、m0・P0 を 0・I に固定、反復は固定 20 回だった。平滑化した状態は真の状態より滑らかなので Q が過小推定され、それが次の反復でさらに滑らかな状態を生んで **Q が 20 反復で下限 1e-8 に潰れていた**（状態方程式が決定論化）。現行は ①W・μ・R を P^s 込みの二次モーメントで更新 ②[A C] を `[z_t; 1]` への同時回帰（P_cross・P_smooth 込み）③Q・R は論文どおり対角 ④x_0 を RTS で 1 歩戻して m0・P0 を更新。Shumway–Stoffer (1982) の欠測版として、各ユニットの観測行は観測された期間だけを使う（全期間観測のユニットは二次モーメント和を共有して行列演算でまとめる）。ドリフト C は論文の基本形に無いが、残す方が良かった（切片なしの試作で、水準 100 の RMSE 0.349 vs 0.401、水準 0 では同等）

**観測式のユニット切片 μ_i（`intercept = TRUE` 既定、1.1.0 で追加）**: 切片が無いと各ユニットの水準を状態が運ぶしかなく、z0・C・A の単位根近傍の間で水準をやり取りする方向に尤度がほぼ平坦になる。水準 100 のパネルでは EM が数万反復その上を漂い、**停止時点しだいで ATT が最大 0.4 動いた**（tol 1e-8・5 万反復でも 10% しか収束しない）。μ_i を M-step で `[m_t, 1]` への回帰として同時推定すると、状態のずれがちょうど切片で打ち消される（反事実が不変な厳密に平坦な方向になる）ので、どの水準でも 100% 収束し tol を 1e-6→1e-8 にしても ATT 差は 0.001。論文 S.3.1.1 の「状態の時不変部分」を W の列空間に縛らない形にしたもの。同じ 20 draws の RMSE（真値 3、水準 0 / 共通水準 100 / ユニット別水準 100）: 切片なし 0.129 / 0.387 / 0.280（後 2 者は tol 次第で動く）、**切片あり 0.161 / 0.161 / 0.196**、ドナー平均の時系列で中心化（論文 S.6.2–6.3 の手順）0.141 / 0.141 / 0.243（30 draws ではユニット別水準の収束 43%）、ユニット別事前平均で中心化 0.162 / 0.162 / 0.202（反復が多い）。水準 0 で悪くなるのは処置ユニットの切片 1 個を事前期間から推定する分の分散。実装後の 30 draws では 0.183 / 0.183 / 0.209。`intercept = FALSE` で論文の基本形に戻る

**収束判定**: `em_tol`（既定 1e-6）で、当てはめ値 μ + W z の反復間の変化を**ユニット平均まわりの変動のノルムで割った**相対変化。生のノルムで割ると、水準の大きいパネルでは変化が小さく見えて反事実が動いている途中で止まる（MC の収束判定を M でなく L にしているのと同じ理由）。`em_iter`（既定 2000）は**上限**で、未収束なら警告する（1.1.0 より前は固定反復数だった）。中央値 350〜400 反復、N=200・T=50 で 0.2 秒

**EM に使うデータは全観測セル（マスク）**: 論文は事前期間だけで学習する（Algorithm 2 `EM_pre`）。全観測セルを使う現行方式の方が良く（RMSE 0.138 vs 0.186 / 0.351 vs 0.412、厳密 EM の試作で比較）、staggered ではこの方式でないと単一フィットにならないので維持している

**カルマンゲインは R 対角なら r×r で解く**（`kalman_smoother_cpp`）: push-through 恒等式 `P W'(W P W' + R)⁻¹ = (I + P W'R⁻¹W)⁻¹ P W'R⁻¹` で N×N の逆行列を避ける（N=200 で 3.9s→0.34s、推定値は 10 桁一致）。EM は常に対角 R を渡すが、一般の R が来たら直接形にフォールバックする。E-step には `Y_obs − μ` を渡す

**`Y_hat` の規約**: TASC だけ `Y_hat` が T×N の**全ユニット**行列（GSC は `Y_tr_hat`、MC は処置列のみを返す）。**消費側が処置列を選ぶ**のが正しい規約 — `synthetic_outcomes()`・`export_json()` は `idx_tr` 列だけを使う。全ユニット平均を使うと plot/augment/export の表示が壊れる（ATT 自体は per-unit gap 由来のため影響しない）。μ は `Y_hat` に含まれる

**staggered はマスク経由**（MC と共通）: `Y_obs` が各処置ユニットを自身の採用時点から NA にするため、単一の状態空間フィットがそのまま staggered fit になる。コホート別の再フィットはしない — `.impute_cohort_fits()`（`utils.R`）が単一 fit の `gap` を採用時点で分割してコホート表を作るだけ。したがって全コホートが同じドナー集合を共有し、`control_group` 引数は持たない（渡すとエラー）。集計は他手法と同じ Clarke 加重。**ユニット等加重にしてはいけない** — コホートの事後長が異なると同一データで他手法と別の推定量になる。SVD 初期化と μ の初期値だけはグローバル `T_pre`（最早採用時点 - 1）の窓を使う（全ユニット未処置の共通窓）
