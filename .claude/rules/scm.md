# SCM（Abadie, Diamond & Hainmueller 2010）

$$Y_{it}^{(0)} = \delta_t + \theta_t Z_i + \lambda_t \mu_i + \varepsilon_{it}$$

重み推定は入れ子最適化: 外側 = V（予測子重み）の座標降下 / L-BFGS-B / multistart、内側 = simplex QP（FISTA + active-set）。推論は `mspe_ratio_pval()`（sharp、MSPE 比率順列検定）と `scm_inference()`（staggered 専用、jackknife 既定 / wild bootstrap）に分離。検証ツール: `placebo_in_time()`（in-time placebo backdating）・`loo_donors()`（V 固定ドナー LOO）。

**Augmented SCM**（`augment_scm()`、Ben-Michael, Feller & Rothstein 2021, JASA）: sharp SCM fit（`coresynth_scm`）に対するリッジ回帰バイアス補正。ドナー横断のリッジ回帰で事後期間平均を予測するアウトカムモデル `beta_hat` を推定し、`tau_aug = tau_SCM + (m_tr_post - sum_j W_j * m_j_post)` で SCM の事前期間フィット不足を補正する。ペナルティ `lambda_ridge` は既定でコントロールユニット横断の LOO-CV により選択する。staggered SCM の partially pooled fit（2022, JRSS-B）とは別の拡張であり、両者を混同しない。**staggered fit に渡すと「Y_co_pre が無い」という誤誘導なエラーになる**（本来は「staggered 非対応」と言うべき軽微な修正漏れ、保留中）。

**sharp SCM の no-op 引数**: `control_group`・（`predictors = NULL` のときの）`scale_predictors` は受理されて無言で無視される。1.0.0 以前からの全手法共通の設計課題で、まとめて対応する予定。

**採用パターンと既定**（BFR 2022 = `papers/Ben-Michael_et_al._2022`。ファイル名 `_2021` は Augmented SCM の別論文なので混同しない）:

| コホート数 | コホート内ユニット数 | 経路 | 既定 |
|---|---|---|---|
| 1 | 1 | sharp | 通常の SCM |
| 1 | 複数 | sharp | **コホート内フルプーリング**（処置ユニットを平均して SC 1 本） |
| 複数 | 任意 | staggered | `nu = "auto"` + `fixedeff = TRUE` |

**同時採用の複数ユニットを平均する根拠は S.4.1**: 「ユニット別適合が ATT 誤差限界に効くのはユニット横断の変動を通じてのみ。同時採用では T1=…=TJ ゆえ S_ρ=S_k=0 なので、誤差限界は ν=1 で最小化される」。S.5.1 の Appendix A.2 階層（コホート内は完全プーリング、コホート間は部分プーリング）と同じ操作。`Y_treat` は平均系列、生の per-unit 系列は `Y_treat_mat`（T×n_treated、staggered の cohort_fits と同名）。`n_treated > 1` では **`mspe_ratio_pval()` を明示エラー**にする — 平均系列は単独ドナーより低ノイズなので比率が過大になり、**帰無で名目 10% に対し棄却率 28%（3 ユニット）・53%（6 ユニット）**と実測済み。

**staggered の既定は `nu = "auto"` / `fixedeff = TRUE`**（v1.0.0 で変更、旧既定は separate / FALSE）。BFR は要旨で separate SCM を「良い結果を生みそうにない」と述べ、S.4.2 で ν を 0 や 1 に近づけないよう勧める。参照実装 augsynth も `nu = NULL` → ヒューリスティック計算、`fixedeff = TRUE` が既定。**ヒューリスティックは augsynth と 4〜5 桁一致を確認済み**（不等コホートサイズを含む 7 構成。v1.0.0 のブロック質量修正後）。S.6 の設計（N=49・T=39・**処置への選択** π_i=logit(θ0+θ1·unit_i)・処置ユニット約 20・sharp null）を再現すると論文の主張が再現する（two-way FE: separate bias −0.0068/MAD 0.0413 → auto −0.0039/0.0395、factor: ν=1 の MAD 0.1492 が auto 0.0607 より大幅に悪い）。**選択を入れない DGP では auto が separate に劣る**ので、再現実験を書くときは selection を必ず入れること。

**ブロック粒度 `pool_cohorts`**（既定 TRUE）: BFR 本体 S.4 の Γ は N×J で**ブロック＝処置ユニット**。Appendix A.2 がその上に「同一採用時点のユニットは完全プーリング」の層を足す（S.4.1 の「コホート内はユニット横断変動ゼロ」が根拠）。既定は付録側。`FALSE` で本体側になる。**BCD ソルバ・ヒューリスティック・診断量・集計はブロックが何を表すか知らない**ので、実装差はブロック構築だけ。参照実装 augsynth の `time_cohort` は既定 FALSE で**論文の付録推奨と逆**。ユニット単位ブロックは `cohort_fits[[i]]$unit` にユニット名が入り、`scm_rank_pval()` の前提になる。**`pool_cohorts` は pooled 経路と `nu = "separate"` 経路の両方に効く**（v1.0.0 で修正。以前は separate 側が引数を持たず黙殺していた）。

**ブロック質量 m_g（Appendix A.2 の核心・v1.0.0 で修正）**: A.2 はコホート問題を**和**で書く — ターゲットが `Σ_i 1{T_i=T(g)} Y_i`、重み制約が `Σ_i γ_ig = n_g`。したがってブロック残差は平均ギャップの n_g 倍で、**q_pool には n_g、q_sep には n_g² が掛かる**。ν̂ = `‖Σ_g m_g gap_g‖ / Σ_g m_g‖gap_g‖`。実装は平均スケールの `b`/`X` を持ち質量を係数側に出す（`Y_synth`・`ATT_g` を生スケールで報告するため）。`.scm_block_target()`（`R/utils.R`）が `mass`/`masses`/`y` を返す。**旧実装はコホートを等加重していた**ので不等サイズで augsynth と最大 0.025 ずれていた。現在は全構成で 4〜5 桁一致（残差は OSQP の許容誤差 1e-4）。等サイズ・1 ユニット/コホートでは共通因子なので正規化で消え、数値は変わらない。

**集計の重み `weights`**（Abadie 2021 S.8）: 処置ユニット名で名付けた数値ベクトル。`.scm_treated_weights()` が**平均 1 に正規化**して返す（等加重なら各 1 → 質量が n_g に一致）。比だけが効くので推定値はスケール不変。staggered では **m_g を n_g の代わりに使う**ので、①ブロックのターゲット系列が加重平均、②pooled 目的関数のブロック重み、③`m_g × T_post` の集計重み、④`scm_inference()` の per-unit 寄与（`unit_masses × T_post`）、⑤`scm_balance_frontier()` の refit、の 5 箇所すべてに一貫して効く。sharp では**プーリング対象が加重平均**になる（`treated_weights` に正規化後の値を保持）。予測子行（`build_predictor_matrices(tr_weights=)`）も同じ重みで平均する — アウトカム側と予測子側が別のターゲットを指さないため。**v1.0.0 以前は staggered でターゲットが等加重・集計だけ加重という混成推定量だった**。

**`scm_rank_pval()`**（Abadie & L'Hour 2021 S.3.2）: 複数処置ユニットの集計 p 値。ユニット別統計量 → 処置割当を B 回置換 → n₁×(B+1) 個をまとめて順位付け → 順位和の極端さ。**ランク化が肝**で、`mspe_ratio_pval()` が平均系列で壊れる（低ノイズゆえ比率が過大）のに対し、比較に入る統計量が全て単一ユニット由来なので歪まない。置換時も採用時点は**スロットに紐づけたまま**にしてイベントタイム構造を保つ。実測サイズは名目 10%/5% に対し τ=0 で 7.0%/4.5%（3 ユニット）・10.0%/3.0%（6 ユニット）、検出力は τ=1.5 で 77%/85%。staggered は `pool_cohorts = FALSE` が必要。

**placebo 剪定 p 値**（`mspe_ratio_pval(mspe_prune=, statistic=)`、ADH 2010 Fig. 5-7 / Abadie 2021 S.3.5）: 事前 MSPE が処置ユニットの `mspe_prune` 倍を超える placebo を順列分布から落とす（ADH は 20/5/2 を使用）。`statistic = "post_mspe"` は比率でなく**事後 MSPE そのもの**を順位付けする Abadie 2021 S.3.5 の変種で、**剪定と組にして使う**。実測: 合成不能なドナーを 5 本混ぜたパネルで、剪定なしの post_mspe は p=0.150（合成できないドナーが分布上位を占める）、`mspe_prune=5` で p=0.029。比率統計量は剪定なしでも p=0.025 で、ADH が Fig. 8 で「比率はカットオフ選択を不要にする」と述べるとおり。**`mspe_threshold` とは別物**（あちらは比率の分母がゼロに近づくのを防ぐ下限）。剪定は一方向検定にも効く。`plot.scm_placebo()`/`plot_data.scm_placebo()` の `mspe_prune` は既定 `NULL` で**検定が使ったカットオフを引き継ぐ**（絵と p 値が同じ placebo 集合を指すため）。`Inf` を明示すれば全件表示に戻る。

**`scm_balance_frontier()` / `plot.scm_frontier`**（BFR S.4.2）: ν グリッドで再フィットし `q_sep`/`q_pool` のトレードオフ曲線を返す。論文が「実務で partially pooled SCM を使ううえで重要なツール」と呼ぶもの。再フィットには `Y_all`・`control_group`・`pooling$fixedeff`・`pooling$pool_cohorts` が要るので staggered fit はこれらを保持する。曲線は凸で、実測では ν 0→0.5 が pooled 不均衡 −21% / per-block +6%、0.75→1.0 が −8% / +39%。**`cov_method = "balance"` のフィットでは `q_cov_sep`/`q_cov_pool` 列も返す** — 正規化定数が脚注 7 の combined なので `q_*_rel` は ν=0 で 1 にならず、アウトカム側だけ見るとトレードオフしていないように見える（実測で ν 0→1 に q_sep 0.451→0.392・q_pool 0.331→0.191 と**両方下がる**のは、上がっているのが q_cov_sep 0.565→1.160 だから）。print と plot の caption がこれを明示する。

**ν̂ がノイズ平均化を拾う件**: 選択のない DGP では各ブロックが既にノイズ下限まで当たっており、ブロック別ギャップはほぼ独立なので平均すると 1/√J に縮む。結果 **ν̂ ≈ 1/√J** となり、プーリングで除去できる不均衡量とは無関係な値が出る（実測: 選択なしで ν̂ 0.733/0.569/0.531 に対し 1/√J 0.707/0.535/0.444）。真の信号は「プーリングで減らせる pooled 不均衡の割合」（選択なし 20〜65%、選択あり 80%）だが ν̂ はこれを使わない。**ノイズ下限の推定なしに両者を分離できず、BFR にも augsynth にも無い独自ヒューリスティックの発明になるため既定は変更していない**。利用者には frontier で判断してもらう。

`nu = "separate"` は per-cohort 経路（V 最適化・ドナー filtering つき）。`donor_mspe_threshold`/`lambda_pen`/`v_selection="oos"` 併用時は既定が自動で `"separate"` にフォールバックする（明示の数値 ν はエラーのまま）。**フォールバックは原因の引数を名指しする message を出す** — 既定が pooled になった以上、無言で推定量が変わるのは `predictors = NULL` の message を足したのと同じ理由で不可。`predictors = NULL` 限定（`covariates` の partial-out のみ対応）。

**staggered fit が解決後の設定を記録する**: `nu`（pooled なら採用された数値、per-cohort 経路なら `"separate"`。どちらの推定量だったかを保存オブジェクトから判別する唯一の手掛かり）・`qp_solver`（staggered は自前で QP を解くので常に `"active_set"`）・`fixedeff`・`pool_cohorts`。

**`covariates` は staggered 限定**（v1.0.0 で sharp を明示エラー化。以前は sharp で黙って無視されていた）。SCM 系の論文は共変量を一貫して**バランス**で扱う（ADH 2010 S.2.3 の V 加重予測子、BFR 2022 S.5.2 Eq. 11 の ξ 加重バランス項。BFR S.4 に「where Abadie et al. (2010, 2015) balance auxiliary covariates, we focus exclusively on lagged outcomes」とある）。partial-out は SDID にバランス機構が無いため Clarke et al. (2024) S.2.2 / Kranz (2022) が入れた装置で、staggered SCM は `predictors` が使えないから借りているだけ。sharp は `pred("x", 前処置期間, "mean")` で論文どおり balance できる。**BFR S.5.2 Eq. (11) の balance 形式は `cov_method = "balance"` で実装済み**（2026-09-20、既定は後方互換のため `"partial_out"`）。各共変量の前処置期間平均を `.scm_cov_balance_matrix()` でユニット別ベクトルにし、never-treated の平均・SD で標準化してから `xi_sd` を掛ける（ノルム内で 2 乗されて ξ になる。論文が ξ を分散と書きながら実装は SD を掛けるのはこのため）。BCD のブロック部分問題には `Xz'Xz` 項が足されるだけで simplex QP のまま。**正規化は脚注 7 どおり combined**（`C_sep² = q_sep² + ξ q_X_sep²` を ν=0 解で評価）なので、balance 時の `q_sep_separate` はアウトカムのみの値ではない。ν̂ はアウトカム側のみで計算（論文 S.4.2 の定義。augsynth も同じ）。ξ 既定は「最終採用時点より前の never-treated アウトカムの標本分散」。**pooled ソルバ限定**（`nu="separate"`/`lambda_pen`/`donor_mspe_threshold`/`v_selection="oos"` とは明示エラー）。**`xi` もバランス項が目的関数に入らない経路（sharp・`cov_method="partial_out"`）では明示エラー**にする — 受理して無視すると `.check_method_args()` が潰した静かな no-op を 1 段深いところで再現してしまう。検証は ξ→0 で outcomes-only に ξ 比例で収束（|Δ| 2.66e-4 → 2.66e-12）・ξ 増で共変量不均衡が単調減・アウトカム不均衡が単調増。**augsynth とは 2 点ずれる**: ①ξ の参照群（論文は never-treated、augsynth は treated のラグアウトカム SD）②正規化（論文は combined、augsynth はアウトカムのみ）— 論文側を採った。`fixedeff` は各ユニットを自身のプリ平均でデミーンした weighted DiD 形式；報告される `Y_synth` はこの shift を戻した生スケール。

## 内側 QP・外側最適化

- **内側 simplex QP**: FISTA に適応リスタート（O'Donoghue & Candès 2015）を導入している。事前アウトカムの共線性で Q 行列が悪条件になりやすく、リスタートなしだと反復数が条件数に比例して膨張するため。解は quadprog と高精度で一致する
- **外側 V 最適化は非凸**。単一スタート（座標降下・BFGS）は予測子つきの経路で悪い局所解に停留しうる（ADH 原論文の重みを再現できないケースを確認済み）。既定 `v_optim = "auto"` は predictors 指定時 `"multistart"`、outcomes-only 時 `"coord_descent"`（outcomes-only では局所解問題が実害として出ていないため軽い方を使う）
- **outcomes-only 標準形の自動ルーティング**: predictors が「outcome 変数のみ・各 `pred()` が単年・前処置全期間をちょうど 1 回ずつ被覆」（`.is_outcome_only_spec()`、単年窓では op 不問・順序不問）なら X0/X1 が前処置アウトカム行そのものになるため、`predictors = NULL` と同一の outcomes-only 経路に落とす（message あり）。Synth はこの per-year special.predictors 指定を outcomes-only の標準形とするため、同じモデルの 2 通りの書き方が同一の解を返すことを保証する措置。`v_optim = "multistart"` / `"bfgs"` の明示指定時はルーティングせず予測子経路を尊重する。**被覆判定の基準は `data` が持つ前処置期間**なので、同じ `predictors` でも `data` の年範囲次第で経路が変わる（プロット用に古い年を足すと外れる）。単年アウトカムラグだけの spec が完全被覆に届かない場合は「n/T_pre しか被覆していない・外側評価は全前処置期間・`v_window` かデータ部分集合で動かせる」旨を message で告げる — 無言でモデルが変わらないようにするため。外側評価窓だけを動かしたいなら `v_window`（`data` は切らない）
- **multistart の設計**: 決定的な複数スタート（uniform / one-hot / 固定シード Dirichlet 乱数）を warm-start QP でスクリーニングし、上位候補のみ Nelder-Mead↔座標降下で磨く。**評価子は KKT 検証済みの解のみ許可**する — 未収束の内側解を通すと外側目的が不正確になり最適化が迷走するため。座標降下が返す (V, W) は暗黙に非整合ペア（W はスイープ中の中間解）なので、**(V, W, loss) は必ず三つ組で追跡**し、ベスト V から W を再導出しない。placebo は（ドナー×候補）をまとめて並列化する — ドナー単位で並列化すると最も遅いドナーが1コアを占有し他コアが遊ぶため。OpenMP のネスト（multistart 内部の並列 × placebo の並列）は `omp_in_parallel()` でガードし二重並列によるオーバーサブスクリプションを避ける
- **NNLS レスキュー**（`use_nnls` フラグ、既定 false・multistart 内部限定）: 縮退したドナー幾何（ほぼ重複する予測子行）では厳密な active-set 解法が毎回コールドスタート FISTA にフォールバックし遅い。Lawson-Hanson NNLS で非ゼロサポートだけを先に推定してから同じ厳密ソルバに渡すことで解消する。**KKT 検証ゲートは変わらない**ので厳密性は落ちない。plain `coord_descent`・oos・staggered・placebo の通常経路ではこのフラグは常に false
- **内側 QP は k 次元の因子形式 `(B, b)` で持つ**（`B = diag(sqrt(V)) X0` は k×N、`b = sqrt(V) * X1`）。N×N の Gram `Q = B'B` は**一切作らない** — rank は高々 k なので、予測子が少なくドナーが多いほど Q は最大限ランク落ちし、作るコストが最も高く情報量が最も少ない。勾配 `Qw - c = B'(Bw - b)` は O(kN)、face solve は O(k²m)。V の 1 座標変更は B の作り直し（O(kN)）で表現する（旧実装の Q への rank-1 更新に相当）
- **face solve は 3 経路**（`face_solve`、いずれも同じ最小解を返す。選択はコストのみ）:
  - `cheap_face = TRUE`（outcomes-only 限定）は (m+1)×(m+1) の bordered-KKT 直接 solve を**まず試す**。V が密で fit を担う face の条件が良いときに最も軽い。**失敗したら諦めずに下の厳密経路へ落とす** — 旧実装はここで false を返して FISTA にフォールバックしており、m が face Gram のランクを超えると saddle 系が特異になって毎回 FISTA（tol 1e-6 止まり）に落ち、外側 V 最適化が不正確な目的関数を読んでいた
  - `m > k`: 和制約のヌル空間を**因子側で**解く。`w_A = w0 + pinv(B_A P)(b - B_A w0)`、`P = I - 11'/m`。任意の正規直交基底 Z について `B_A P = (B_A Z)Z'` かつ Z' は co-isometry なので `pinv(B_A P) = Z pinv(B_A Z)`、すなわち Helmert 経路と打ち切りまで含めて同一解を O(m³) でなく **O(k²m)** で得る。予測子 fit（m がドナープール規模まで伸びる）を担うのはこの経路
  - それ以外（`m <= k`）: Helmert 基底を明示的に作る m 空間の経路。m ≤ k ではこちらが安い
- **打ち切り閾値の対応**: ヌル空間経路は face Gram の最大固有値の 1e-9、因子経路は最大特異値の sqrt(1e-9)。λ = σ² なので同一の閾値
- **縮退した QP では解が一意でない**: k < サポートサイズのとき最適解は面（連続無限個）になり、返る W は「どれか 1 点」でしかない。active-set の入替判定 `lam.index_min()` は同点をノイズで決めるため、**演算順序を変えるだけで別の（同じく厳密な）最適解に着地する**。したがってこのソルバに bit 再現性を期待してはいけない。回帰チェックは重みの一致ではなく (a) 各 fit 自身の V での KKT 残差、(b) 内側 QP の目的値、(c) 外側が実際に最小化している目的関数、で行う（`sandbox/28_tier1_qp_refactor_check.R`）。予測子を集約窓で数本だけ指定する仕様では内側目的値が 1e-30 まで落ちる（処置ユニットの予測子ベクトルがドナー凸包の**内部**にある）ことがあり、そこでは重みも報告される outcome fit も完全に恣意的になる
- **outcomes-only の座標降下は Gram 形式**（`active_set_simplex_gram()`、`cheap_face && 2k >= N` のとき）: 因子形式は k が小さい予測子経路のための設計で、outcomes-only（k = T_pre ≈ N）では各ピボットで face Gram `B_A'B_A` を O(k m²) で作り直すのが支配的になる。座標降下の V 1 座標変更は Q へのランク 1 更新なので、Q_base（スイープ毎に作り直し、受理時にランク 1 更新＋正規化）と `(x_j, dv)` を**暗黙に**持つ — グリッド点毎に N×N の Q_g を実体化すると並列プラセボがメモリ帯域で詰まる（実測 1.2 倍遅い）。face 解は同じ bordered-KKT / Helmert 経路（`face_solve_bordered()`/`face_solve_helmert()` に切り出し済み）、KKT ゲートも同じ。Wolfe・NNLS レスキュー指定時は因子形式のまま
- **cold start は FISTA → active-set**（`fista_simplex(cold = TRUE)`、`scm_inner_weights_cpp` が使用）: 一様初期値から active-set を始めると全ドナーを 1 本ずつ落とす各ピボットで m≈N の face を解くことになり、0.4.1〜1.0.0 の outcomes-only 速度後退（N=100・T_pre=96 で 15 倍）の主因だった。先に FISTA で support を絞り、最後に active-set で KKT 検証済みの厳密解にする。Wolfe は corral を 1 点から育てるので presolve しない（`presolve = cold && !wolfe`、Wolfe 失敗時の NNLS レスキュー順も不変）
- **`scm_inner_weights_cpp` は厳密解を返す**: 以前は tol 1e-6 の FISTA を最適性ゲートなしで回しており、KKT 残差が 1e-2 に達することがあった（= ドキュメント通りの問題を解けていなかった）。現在は本経路と同じ warm-start active-set を通し、FISTA はフォールバック。この関数は oos の最終 refit・bfgs・`loo_donors()`・`conformal_inference()`・`scm_design()`・座標降下の初期候補の重みを供給するため、影響範囲が広い
- **`qp_solver = "wolfe"`**: Wolfe (1976) 最小ノルム点法。`X0 w` は R^k のドナー凸包を描くので内側 QP は k 次元多面体への射影であり、カラテオドリの定理よりサポート ≤ k+1 の最適解が必ず存在する。corral を 1 点から育てる（全ドナーから削るのではない）ので face solve は N_co に依らず O(k³)、有限終了・KKT 検証済み。**非縮退なら active_set と同一解**（Prop 99 outcomes-only で重み・loss とも 1e-15 一致）。縮退時のみ差が出て、そこではスパースかつ再現可能な側が返る。oos・lambda_pen・bfgs・staggered は R 側で独自に `solve_simplex_qp()` を呼ぶためフラグが届かず、明示エラーにしている
- **`qp_solver` の既定は `"auto"`（v1.0.0 で切替済み）** = 縮退しうる経路（予測子つき sharp、および `2·T_pre < N_co` の outcomes-only）では `"wolfe"`、それ以外の outcomes-only と自前で QP を解く経路（oos・lambda_pen・bfgs・staggered）では `"active_set"`。outcomes-only で一律 Wolfe にしていた当初案は、座標降下の各内側問題を cold start するため **同一の重みで 3 倍遅く**（Gram 形式の active-set 比では 14 倍）、既定 fit の速度を大きく損ねていた。`2·T_pre ≥ N_co` の規則は Gram 形式の切替と同じ基準で、40 パネルの照合で HEAD 既定と重み・プラセボとも 1e-13 一致を確認済み。単純に既定を `"wolfe"` にすると除外経路が軒並みエラーになるため `"auto"` を挟んでいる。**明示的な `"wolfe"` は除外経路でエラーのまま**（無言の降格をしない）。解決後の値が `fit$qp_solver` に入るので `mspe_ratio_pval()` の placebo バッチが同じソルバを写せる。縮退した予測子指定では単なる tie-break の差にとどまらず、**外側 V 探索が到達する loss 自体が改善する**（N_co=30・予測子 1〜2 本で loss 3.25→2.75 / 3.31→2.79、非ゼロドナー 13→3 / 17→2）。内側解がスパースで安定だと非凸な外側目的が評価しやすくなるため。outcomes-only は非縮退なので機械精度で不変
- **`v_window`**（sharp SCM 限定）: 外側 V フィットの評価行だけを制限する。X（予測子行列 or outcomes-only の全プリ行）と報告される `loss`（全プリ期間）は不変。`v_selection="oos"` と staggered とは併用不可
- **OOS V 選択**（`v_selection="oos"`, outcomes-only, Abadie 2021 §3.2 準拠）: プリ期間を訓練半分と検証半分に分割し、W(V) は**訓練半分のみ**でフィットする（検証行を QP に含めると V が検証行に質量を寄せて検証 MSPE を人為的にゼロにできるリークが起こる）。V は検証 MSPE 最小化で選び、最終 W は V* を用いて直近の半分に再フィットする
- **予測子 SD スケーリング**（`scale_predictors = TRUE` 既定）: 各予測子を全ユニット横断 SD で除算する。スケールの大きい予測子が V 加重損失を支配するのを防ぐため。W 自体はスケール不変

## staggered・推論

- **partially pooled の解法**: コホート単位の巡回ブロック座標降下（他コホート固定下では標準 simplex QP に帰着）。イベントタイム整列時の欠損ラグはゼロ詰め。`nu` は `donor_mspe_threshold`/`lambda_pen`/`v_selection="oos"` と併用不可（pooled 経路は outcomes-only・uniform lag weights を前提とするため）
- **既定のドナーは never-treated のみ**（v1.0.0 で `"clean"` から変更、`"clean"` は非推奨警告）。理由は CLAUDE.md の Staggered 共通仕様。BFR の D_jK = {T_i > T_j + K} は推定窓 k ≤ K とセットであり、coresynth はコホート効果をパネル末尾まで平均するので K = T_post_g − 1 相当 → never-treated に一致する。augsynth は `n_leads`（既定 = 最短ポスト期間）で窓を切るので将来採用者を使える — **coresynth で not-yet-treated を正しく入れるには推定窓の打ち切りが必要**で、全推論関数の「事後行 = T_pre+1..TT」前提に波及する
- **jackknife の速度**（N=200 で 26.7s → 3.0s）: ①どのブロックでも最終解・ν=0 解の両方で重み 0 のドナーは再推定しない（縮小問題でも元の解が最適のまま＝厳密に ATT）。ν=0 解は `pooling$separate_weights` に保存 ②再推定は元の解から warm start（`.fit_scm_staggered_pooled(warm=)`、ブロックキーは cohort か unit ラベル）。**縮退ブロック（T_pre ≪ ドナー数）では着地点が cold refit と違い得る**（N=100 で推定値最大 0.027・SE 1.6% 差）が、cold 側も同じく恣意的 ③`solve_simplex_qp(lipschitz=)` に λ_max(FF')（F は数十行の積み上げ因子）を渡し、呼び出し毎の N×N `eig_sym` を省く — これが大パネルの pooled fit 時間の大半だった（結果は HEAD と 1e-14 一致）。N=400 はなお約 80s（1 回の pooled fit 0.38s、FISTA の O(N²) 勾配が律速）
- **`scm_inference()` の既定は jackknife**（BFR 付録 A.1）: ν をフィット値に固定し、ドナーを含む全 N ユニットを 1 つずつ落として再フィット、V = (n−1)/n Σ(ATT^(−i) − 平均)²、正規近似の CI・p 値。`.scm_jackknife_estimates()` が `.pan_from_staggered_fit()`（fit の `T_adopt` から復元）で再構築し、pooled 経路は `.fit_scm_staggered_pooled()`、separate 経路は fit に保存した `separate_args` で `.fit_scm_staggered()` を呼ぶ。partial-out 済みアウトカム・balance の Z は固定（再推定しない）
- **wild bootstrap**（`method = "wild_bootstrap"`、BFR S.5.3 / **Otsu & Rai 2017 Eq. 9**、`.scm_wild_coefs()`）: パネルの全ユニットに独立な黄金比 2 点乗数（Otsu & Rai Eq. 8）を掛ける。処置 i の係数 = ω_i(τ_i − ATT + Σ_d γ_d e_d)、ドナー d の係数 = −Σ_b ω_b γ_db e_db、e は二方向（ユニット＋期間）モデルに対する残差＝ブロックの DiD 変化量からドナー平均変化を引いたもの。全乗数 1 で係数和は厳密に 0。**Otsu & Rai で裏付けが取れた 2 点**: ①ドナー（マッチに使われた統制）の残差も各自の乗数で揺らすのが方法の核心（旧実装は処置側だけで、N_co=8・コホート内 8 で被覆 80%、J=2 で 45% と過小被覆していた）②**ATT で中心化するのは処置側の異質性項 ν_i だけ** — BFR Eq. 13 の字面と augsynth `weighted_bootstrap_multi` は全ユニットを中心化するため SE が ATT に比例して膨らむ（SE 1.19 vs SD 0.16）。期間効果を残差から除くのは、共通ショックが乗数に拾われて SE が膨らむのを防ぐため（テストで ATT+10・共通ショック+5 に対し SE 不変を確認）。被覆は 9 設計で 93〜99.5%（J=2 で 93%）と保守的 — 二方向モデルが吸収しない因子構造が残差に残るため（BFR 付録 Fig. B.3 の「やや保守的」と同じ傾向）。再推定不要なので jackknife が重い大パネル向け。処置ユニット 3 未満で警告
- **OpenMP 並列化**（`src/inference.cpp` の `scm_placebo_cpp`/`scm_placebo_x_cpp`）: per-control-unit の placebo イテレーションは書き込み先が独立インデックスのため完全並列化できる。壁時間は最も遅い1ドナーで律速される（コア数を増やしても短縮しない）
- **OSQP は不採用**: 座標降下が simplex QP を1フィットあたり数万回呼ぶ構造上、OSQP の初期化・前処理コストが累積して不利。FISTA + simplex 射影の方が N_co ≤ 50 で優位
