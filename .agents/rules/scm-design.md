# SCM-Design（Abadie & Zhao 2026）

実験設計段階で処置候補を選ぶ 3 バリアント（`"base"` / `"weakly_targeted"` / `"unit_level"`）＋ ブランク期間順列検定・スプリット共形 CI。

- **eq. (9)/(10) の解法**: 処置候補集合 `S` を総当たり列挙し `S` ごとに `(w, v)` を最適化（原著付属コード `SCDesign` と同じ戦略、非凸 QCQP は不使用）。`weakly_targeted`（eq. 9）は `S` 固定下で 2 ブロック交互最小化、`unit_level`（eq. 10）は `v` 分離後の per-unit loss を `c = X_S'X_bar - (xi/2) * loss` として `solve_simplex_qp()` に直接渡す（`X_S'X_S` の逆行列経由で目標ベクトルへ畳み込むと特異時に線形項の一部が落ちるため禁止）
- **同点タイブレーク**: 重み 0 のユニットだけが異なる候補集合（`unit_level` で `xi` 大のとき頻発）は目的値が一致し丸め誤差で勝者が変わり環境差でテストが壊れるため、相対差 `1e-10` 未満は同点として列挙順で先の集合（小さい方）を残す。`treated_units` は候補集合 `S` であり `w` のサポートではないため、実効ユニットを見るテストは `w > 0` で比較する
- **共形 CI と乱数管理**: 式 (18) の経験分布下限に従い **`quantile(type = 1)`** を使う（既定 `type = 7` は不可）。組み合わせ数が 1 万を超えるときの順列サンプリングは固定 seed 42 を使いつつ、呼び出し側の `.Random.seed` を必ず保存・復元する
