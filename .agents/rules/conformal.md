# Conformal Inference（Chernozhukov, Wüthrich & Zhu 2021）

`scm` / `sdid` / `gsc` / `mc` / `si` の sharp fit 限定（staggered / multi-arm / TASC は明示エラーで各 `*_inference()` へ誘導）。

- **全 T 期間での再推定**: 帰無 `H0: tau = tau0` の下で処置後を `Y1 - tau0` に補完し、全 T 期間で反実仮想を再推定する（事前期間のみだと有限標本妥当性が崩れる、CWZ S.2.2）。共変量つき fit は残差化済み行列をそのまま使う
- **対照側計算の事前キャッシュ**: test inversion で変わるのは処置系列 `y1` のみのため、`.conformal_prepare()` で `y1` 非依存部分（GSC の Step 1 因子・`beta`・加法的効果、SI の射影行列）を 1 回だけ計算して `.conformal_refit()` へ渡す（省略時も単発動作は維持）
- **信頼集合の境界判定**: p 値は `1/T` の離散値で `alpha * T` が整数だと境界に乗るため、CWZ Algorithm 1 に従い `p > alpha + 1e-9`（`>=` 禁止）で判定する
- **既定グリッドの自動拡張**: 初期グリッド端の候補が受容されている場合、棄却点が見つかるまで最大 6 回（倍々幅・`n_grid/4` 点ずつ）外へ探索し、初期グリッド刻みまで二分法で詰める。ユーザー指定 `grid` は拡張せず、端が残れば警告する（片側検定の対立仮説側は探索・警告とも行わない）
- **p 値下限と非有界性**: 恒等シフトが必ず数えられるため p 値の下限は `1/T`。`T < 1/alpha` では何も棄却できず拡張も止まる。また `T_post` が `T` の半分程度あるパネルでは、SCM 以外が段差を前後半に配分して全シフトで同統計量になり非有界になりやすいが、これは CWZ の「事後期間が短い」前提外による性質であり不具合ではない
